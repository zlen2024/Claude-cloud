# Source follower

**Objektif:** fahami kenapa gandaan source follower kurang daripada 1 dan bagaimana menghampirinya.

## Teori ringkas
Dalam source follower output diambil pada source, jadi isyarat tidak songsang dan gandaan hampir 1 (fasa 0°).
Gandaan ≈ gm · RL' / (1 + (gm + gmb) · RL'), di mana RL' = RL ∥ ro. Ia sentiasa kurang daripada 1 dan
bertambah bila gm · RL' besar. **Kesan badan** (gmb, bulk ke 0 tetapi source naik) mengurangkan gandaan lagi.

Rintangan keluaran ≈ 1/gm yang rendah, itulah sebabnya follower dipakai sebagai penimbal.

## Tugasan
1. Jalankan, baca gandaan linear (10^(dB/20)). Dengan W = 3 dan RL = 5k ia kira-kira 0.63.
2. Naikkan gandaan kepada lebih 0.78 dengan menukar W dan RL. Kekalkan f-3dB lebih 100 MHz.
